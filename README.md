# Bike Shop Customer Analysis

## Project Overview
This project analyzes customer data from a bike shop to identify key factors influencing purchase decisions.

The analysis includes:
- Data cleaning and preprocessing
- Missing data imputation (MICE)
- Exploratory Data Analysis (EDA)
- Decision Tree classification
- Customer segmentation (K-means)
- Statistical testing (ANOVA, Kruskal-Wallis)

## Key Techniques
- R (dplyr, ggplot2, rpart, mice)
- Machine Learning (Decision Tree)
- Clustering (K-means)
- Data Visualization

## Dataset
Customer survey data including:
- Income
- Education
- Marital status
- Commute distance
- Region
- Purchase decision

## Results
- Identified key drivers of bike purchase
- Built classification model predicting purchase behavior
- Segmented customers into meaningful groups
